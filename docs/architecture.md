# PrimeBasket Architecture

## Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router

## Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven
- REST APIs

## Database
- MySQL

## Main Modules
- Authentication
- Products and categories
- Cart and orders
- Wishlist
- Payments and gift cards
- Returns and customer support
- Admin dashboard

## Security
- Use environment variables for secrets.
- Never commit credentials, tokens, or .env files.
